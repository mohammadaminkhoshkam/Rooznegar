Rooznegar

Project time tracking for Windows: see where your time really goes.

Quick start

  1. Run Rooznegar-Setup-2.0.0.exe. It installs for the current user only and does not need administrator rights.
  2. On the Dashboard, click the play button on a project card, or one of the quick-start buttons at the top, to start tracking.
  3. To switch, start another project. The previous activity ends at that exact moment, so not a second is lost.
  4. To finish, click Stop or press Ctrl+Alt+Space from anywhere in Windows.

How the timer behaves

SituationWhat happens
Starting another projectThe current activity ends and the new one starts at exactly the same moment.
Sleep / hibernateBy default the whole period counts toward the running project. To be asked instead, turn on Ask about sleep time in Settings.
Away from the PC (awake)Idle detection asks you; nothing is removed without your answer.
Crossing midnightTracking continues and each part is filed under its own day; the timesheet labels it Multi-day.
Closing the windowRooznegar stays in the notification area and keeps tracking. While tracking, its icon shows a dot in the project's color.
Quit / normal Windows shutdownThe timer ends at that moment and the data is saved.
Power loss / crashOn the next start you can keep tracking (counting the time in between) or end the activity at the last saved moment.

Manual entries and edits

On the timesheet, click Manual entry (Ctrl+M). Choose a project, pick the dates from the calendar and type the times; 9:30, 09:30:05 and 930 are all accepted. An end time earlier than the start time means the activity crossed midnight. The duration is shown before you save.

To edit an activity, double-click its row or click the pencil button. The range must be in the past and must not overlap another activity or the running timer. Deleting a multi-day activity removes all of its parts, and Undo brings it back for a few seconds.

Archiving or deleting a project

Click the pencil on a project card (or double-click the card). Archive hides the project from the active list while all of its records stay in the reports. Delete project removes the project and all of its activities; before deleting, Rooznegar shows how many activities and how much time will be removed, and stops the timer first if that project is running.

Deleted something by mistake? Click Undo at the bottom of the window within a few seconds. The daily backups in the data folder are another way back.

Reports, export and backup

On Reports, choose a range: this week (from Monday), last week, this month, last month, this year, all time, or a custom range. Hover over bars, donut slices or heatmap cells to see details.

The CSV export opens in Excel. It is UTF-8 encoded and has the columns Date, Project, Start, End, Duration, Duration (seconds), Note and Type.

Rooznegar saves every 15 seconds and keeps the previous version (.bak) plus up to 30 daily backups. In Settings you can create a backup file or restore one; a copy of your current data is saved before restoring. Data location:

%LOCALAPPDATA%\Rooznegar\data.json

Your data stays on this PC. Uninstalling Rooznegar does not delete it.

Accuracy

Time is calculated from differences between UTC timestamps, not by counting timer ticks; days follow the Windows time zone, so the Windows clock and time zone must be correct. The time logic, midnight splitting, manual entries, idle-time removal, streaks, project delete and undo, and saving and recovery are covered by 50 automated tests. Unexpected errors are written to errors.log in the data folder instead of closing the app.
